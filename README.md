## What I Do

I am a **Senior Full Stack Developer** focused on building modern, fast, and maintainable web applications for startups, agencies, SaaS products, and businesses.

My work usually sits around:

- Full stack web app development with **Next.js, React, TypeScript, Node.js, and NestJS**
- Backend API development with **REST APIs, authentication, roles, validation, and databases**
- Database work with **MongoDB, PostgreSQL, Redis, and scalable schema design**
- Frontend development with **responsive UI, clean UX, Tailwind CSS, and reusable components**
- Code optimization, refactoring, performance fixes, and production stability
- Deployment and hosting with **Docker, Nginx, PM2, VPS, SSL, and CI/CD workflows**
